# ELFIS WISSENSBASIS

Diese Dateien dürfen direkt mit einem Texteditor gepflegt werden.

Jeder Wissensabschnitt beginnt mit einer Überschrift:

## Thema
SCHLAGWÖRTER: Wörter und Formulierungen, unter denen Elfi das Thema finden soll
- Eine belegte Information als vollständiger Satz.
- Eine weitere belegte Information.
- [OFFEN: Diese Zeile durch eine echte Information ersetzen.]

WICHTIG

- Nur sichere und für die Veranstaltung gültige Fakten eintragen.
- Jede Aussage in eine eigene Zeile mit Bindestrich schreiben.
- Mehrere gebräuchliche Begriffe als Schlagwörter ergänzen.
- Zeilen mit [OFFEN: ...] werden von Elfi vollständig ignoriert.
- Unbekannte Angaben nicht schätzen. Die Lücke lieber offen lassen.
- Kurze, eindeutige Sätze funktionieren besser als Werbesprache.
